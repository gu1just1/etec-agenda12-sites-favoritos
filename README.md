## Abrir o projeto

Extraia toda a pasta e abra `index.html` no navegador. Mantenha a pasta `imagens` ao lado do arquivo HTML. As cinco imagens estão incluídas e são carregadas localmente. Os links precisam de acesso à internet.

## Conteúdo

- Título da aba: Meus sites favoritos.
- Título do corpo com o nome completo do aluno.
- Cinco sites: YouTube, Spotify, GitHub, Google e Portal Etec.
- Nome acima de cada imagem e link abaixo dela.
- Código comentado e capturas na pasta `capturas`.
- HTML e CSS, sem bibliotecas ou instalação.
